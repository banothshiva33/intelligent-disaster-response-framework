# Java Spring Boot Backend

This directory will hold the Java Spring Boot backend application for the Intelligent Disaster Response Framework.

## Implementation Details (Future Phase)
* **Framework:** Spring Boot + Maven.
* **Database Driver:** Spring Data (NoSQL/MongoDB integration).
* **Security:** JWT authentication and Role-Based Access Control (RBAC).
* **Services:** APIs for reporting, Multi-Source Verification (MDVF), and volunteer dispatches.
